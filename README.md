# Projet_Accelerometre
Projet de création d'un accéléromètre avec un raspberry pi 2

# Accelerometer/G-meter project
Creation of a custom accelerometer using a raspberry pi 2



Liste de matériel/What's needed
| Élément | Détail | Prix indicatif |
| Raspberry Pi 2 modèle B (ou plus récent) | Pi 3B/4 plus simple si tout est à racheter (WiFi intégré) | 35-55€ |
| Carte microSD 16-32 Go (classe A1/A2) | Pour Raspberry Pi OS | 8-12€ |
| Alimentation officielle 5V/2.5A micro-USB | Éviter une alim sous-dimensionnée | 8-10€ |
| Dongle WiFi USB | Le Pi 2 n'a pas de WiFi intégré | 8-12€ |
| Câble Ethernet (optionnel) | Alternative pour la config initiale | 5€ |
| Breadboard 830 points | Format standard | 5-7€ |
| Kit de fils Dupont (M-M, M-F, F-F) | ~120 fils | 6-8€ |
| Kit de résistances assorties (optionnel) | Utile pour LEDs de statut | 5€ |
| MPU6050 (module GY-521) | IMU 6 DOF, accéléromètre+gyroscope 3 axes, I2C, ±2g à ±16g | 3-12€ |
| Écran TFT 2,8" ILI9341 (SPI) | 320x240, tactile ou non | 10-20€ |
| Alternative écran OLED SSD1306 0.96" (I2C) | Plus simple, monochrome | 5-8€ |
| Boîtier Raspberry Pi (ou impression 3D) | Protection mécanique | 5-10€ |
| Adaptateur allume-cigare → USB 5V | Alimentation dans la voiture | 8-10€ |
| Support/fixation (velcro, bras articulé) | Tenir l'écran visible | 5-10€ |
| Clavier + souris USB basiques (optionnel) | Si pas de SSH | 10-15€ |
| Câble micro-HDMI vers HDMI (optionnel) | Pour setup avec écran classique | 5€ |
